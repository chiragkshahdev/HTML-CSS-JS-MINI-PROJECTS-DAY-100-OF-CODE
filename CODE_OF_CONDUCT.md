# Code of Conduct - 100 Days of Code

## My Pledge

I am a 1st Year BSIT student. This repository is my 100 Days of Code journey.
My goal is to learn daily, stay consistent, and keep this space respectful
and helpful for everyone.

## Our Standards

### 1. Respect Everyone
Everyone is here to learn. Do not make fun of anyone's code, questions, or mistakes.

**Example - Good:**
> "Nice try! You have a small error in line 5, you can try this..."

**Example - Bad:**
> "Haha, you don't even know this? So easy."

### 2. No Hate or Abusive Language
No abusive words, hate comments, personal attacks, or discrimination.

**Example - Good:**
> "I disagree with this approach, we can try another way."

**Example - Bad:**
> "You are stupid, don't ever comment here."

### 3. Help, Don't Show Off
If someone doesn't understand, help them. Don't try to prove you are smarter.

**Example - Good:**
> "I faced the same problem. Here is how I solved it..."

**Example - Bad:**
> "This is too easy, I did it in 2 minutes."

### 4. Give Credit
If you use someone else's code, tutorial, or idea, give them credit.

**Example - Good:**
> "Idea taken from: CodeWithHarry - Python Tutorial"

**Example - Bad:**
> Copying someone's code and writing "Made by me".

### 5. Be Consistent
Try to commit every day. Even a small code is better than no code.

**Example - Good:**
> Day 12 - Practiced 3 Python loops today.

**Example - Bad:**
> No commit for 15 days, then 1 big commit on Day 16.

## For Contributors

1. First, open an Issue and tell what you want to change.
2. Create a new Branch. Do not push directly to `main`.
3. Give feedback politely.
4. Keep your code clean and simple.

**Example - Good:**
> "Hey, I want to add Day 20 solution. Can I create a branch?"

**Example - Bad:**
> Directly pushing changes to `main` without asking.

## Enforcement

If someone breaks the rules:

1. **First Time:** We will explain politely.
2. **Second Time:** We will give a warning.
3. **Third Time:** We will block / report.
