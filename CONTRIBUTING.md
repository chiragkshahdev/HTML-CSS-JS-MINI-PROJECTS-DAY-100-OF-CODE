# Contributing Guide - FYBSCIT HTML 100 Programs

Welcome to this repository!
This repo has 100 HTML programs made for FYBSCIT learning.

### About This Project
This is my personal learning project. I made all these 100 programs
by myself for practice and for my portfolio.

You are free to view the code, learn from it, and try it on your laptop.
I hope it helps you in your learning too!

### Folder Structure
`01-hello-world / index.html`
`02-basic-tags / index.html`
`03-table / index.html`

Same pattern till 100 programs.

### Pull Requests
For now, I am keeping this repo personal, so I am not accepting
Pull Requests. This helps me keep all 100 programs original and
track my own progress.

But if you find any mistake, feel free to open an Issue.
I would really appreciate it!

### Feel Free To Use
You can use this code for your learning and your own projects.
Credit is not required. If you want to give credit, that's
really kind of you, but even if you don't, it's totally okay.
