# Day 20 - Spider-Man Web Shooter Effect 🕷️ | HTML CSS JS

An interactive, physics-based Spider-Man Web Shooter built with HTML5 Canvas. Click anywhere and shoot webs that stay!

### 🕸️ Live Demo
[Click here to Play](https://chiragkshahdev.github.io/HTML-CSS-JS-MINI-PROJECTS-DAY-100-OF-CODE/Day%2020%20-%20Spider-Man%20Web%20Shooter/)

> **How to Play:** Click & Hold -> Drag Mouse -> Release. The web will stick where you release!

### 🔥 Features
- [x] Real elastic web with sine-wave animation
- [x] Permanent webs - screen fills up after 50+ shots
- [x] Splat & glow effect where web sticks
- [x] Custom crosshair + hidden cursor = Game feel
- [x] Web counter
- [x] Screen shake on shoot (Thwip!)
- [x] Mobile support - Touch to shoot
- [x] Canvas based - Super smooth 60fps

### 🧠 What I Learned
- HTML5 Canvas API - `beginPath()`, `stroke()`, `shadowBlur`
- Physics - Calculating distance and wavy line with `Math.sin()`
- Mouse events - `mousedown`, `mousemove`, `mouseup` chaining
- Animation Loop - `requestAnimationFrame` for smooth rendering
- How to store permanent drawings in an array

### 🛠️ Tech Stack
- HTML5
- CSS3 (Radial gradients, custom cursor)
- JavaScript (Vanilla + Canvas API)
