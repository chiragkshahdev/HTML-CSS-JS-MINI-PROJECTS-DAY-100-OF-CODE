# Day 26 - Rock Paper Scissors Game

A clean and responsive Rock Paper Scissors game built with HTML, CSS & Vanilla JS.

## Features
- Scoreboard with Player vs Computer
- Emoji-based choice display
- Win / Lose / Draw logic
- Win conditions map: Rock > Scissors, Scissors > Paper, Paper > Rock
- Reset Game button
- Mobile responsive + hover animations

## How to Play
1. Click on Rock, Paper, or Scissors.
2. Computer chooses randomly.
3. Winner is decided instantly.

## Tech Stack
- HTML5
- CSS3 (Flexbox, Gradient)
- JavaScript (ES6)
