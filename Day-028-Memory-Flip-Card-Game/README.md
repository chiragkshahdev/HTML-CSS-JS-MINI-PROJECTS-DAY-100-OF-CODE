# Day 28 - Memory Flip Card Game 🧠

**100 Days of Code Challenge | By Chirag Kiran Shah | BREAK THE CODE OF UNIVERSE**

## 🎮 Demo
4x4 Grid | 8 Pairs | Flip & Match Logic

## ✨ Features
- **Flip Logic:** CSS 3D `rotateY(180deg)` + `preserve-3d` + `backface-visibility`
- **Match Logic:** `dataset.icon` comparison, `lockBoard` prevents 3rd flip
- **Stats:** Moves counter, Timer (mm:ss), Matched pairs
- **Extras:** Hint system (3x), Win modal, Restart, Responsive
