# Day 03 - 3D Tilt Card

A cool 3D Card that tilts with mouse movement using HTML, CSS, & Vanilla JS.

### Features
- 3D Tilt Effect on mousemove
- Glare / Shine Effect
- Smooth Reset Animation on Mouse Leave
- Fully Responsive

### Tech Stack
- HTML5
- CSS3 (transform-style: preserve-3d, perspective)
- Vanilla JavaScript

### How to Run
1. Open 'index.html' in Browser
2. move Mouse over the Card

### Learning Points
- 'perspective: 1000px' on parent container
- 'transform: ratateX() rotateY()' based on mouse position
- 'transform-style: preserve-3d'
