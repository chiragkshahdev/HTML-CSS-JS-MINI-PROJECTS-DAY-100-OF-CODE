# Day 31 - Solar System | Pure CSS

A beautiful, responsive Solar System animation built with only HTML & CSS. No images, no JS needed for animation.

### ✨ Features
- Pure CSS orbits & planet rotations
- Realistic orbit timing (Mercury fast, Neptune slow)
- Responsive & glowing Sun effect
- Asteroid belt included

### 🚀 Demo
Just open `index.html` in browser.

### 🛠️ Tech Stack
- HTML5
- CSS3 (Animations, Transforms)
- Tiny JS for tooltip

### 📂 Structure
- index.html
- style.css
- script.js
