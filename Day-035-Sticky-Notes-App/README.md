# Day 35 - Sticky Notes App

A simple sticky notes app with auto-save functionality. Notes stay even after refreshing.

### ✨ Features
- Add unlimited notes
- Auto-save in LocalStorage
- Delete notes
- Colorful sticky design
- Responsive

### 🛠️ Tech Stack
HTML5, CSS3, JavaScript

### 💾 Storage
Uses browser LocalStorage - no backend needed.
