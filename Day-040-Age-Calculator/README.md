# Day 40 - Age Calculator

Calculates exact age in years, months and days from Date of Birth.

### ✨ Features
- Exact age calculation (not just year difference)
- Handles month/day borrowing logic
- Future date validation
- Clean UI

### 🛠️ Tech Stack
HTML5, CSS3, JavaScript

### 📐 Logic
Calculates difference between today and DOB with proper month length handling.
