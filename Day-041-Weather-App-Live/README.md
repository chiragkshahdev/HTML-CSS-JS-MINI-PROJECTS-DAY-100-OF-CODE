# Day 41 - Weather App Live

Live weather data using OpenWeatherMap API.

### ✨ Features
- Search any city
- Live Temp, Humidity, Wind
- Weather icon from API
- Error handling (city not found)

### 🛠️ Tech Stack
HTML, CSS, JS + OpenWeatherMap API

### 🔑 Setup
1. Go to https://openweathermap.org/api
2. Create free API key
3. Paste in script.js -> `apiKey`

### ▶️ API
`https://api.openweathermap.org/data/2.5/weather?units=metric&q={city}&appid={key}`
