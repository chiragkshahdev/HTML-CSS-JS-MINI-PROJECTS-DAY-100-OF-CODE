# Day 43 - GitHub Profile Finder

Find any GitHub user with live data from GitHub API.

### ✨ Features
- Avatar, Name, Bio
- Followers, Following, Repo count
- Latest 5 repos with stars
- No API key needed
- Error handling

### 🛠️ Tech Stack
HTML, CSS, JS + GitHub REST API

### 🔗 API
`https://api.github.com/users/{username}`

### ▶️ Try
Search: `torvalds`, `virat`, your own username
