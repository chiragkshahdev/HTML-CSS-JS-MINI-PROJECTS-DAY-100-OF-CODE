# Day 44 - Dictionary App

Live word meaning with pronunciation.

### ✨ Features
- Meaning, Part of Speech
- Example sentence
- Synonyms
- Audio pronunciation (🔊)
- No API key needed

### 🛠️ Tech Stack
HTML, CSS, JS + Free Dictionary API

### 🔗 API
`https://api.dictionaryapi.dev/api/v2/entries/en/{word}`
