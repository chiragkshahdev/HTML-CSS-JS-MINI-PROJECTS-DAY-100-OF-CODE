# Day 51 - Form Validation ✅

Professional sign-up form with real-time validation, strength meter & UX polish.

## Features
- Real-time validation (name, email, password, confirm)
- Password strength bar (4 levels) + rules checker
- Show/Hide password toggle
- Terms & condition check
- Submit button disabled until all valid
- Success animation + error shake
- No library, pure Vanilla JS

## Validations
- Name: min 3 chars, only letters
- Email: regex /^[^\s@]+@[^\s@]+\.[^\s@]+$/
- Password: 8+ chars, Uppercase, Number, Symbol
- Confirm: must match password

## Tech Stack
- HTML5 Form API + novalidate
- CSS BEM + Gradient UI
- Vanilla JavaScript (Regex, Events)

## How to Run
Open `index.html` → try typing wrong data to see errors.
