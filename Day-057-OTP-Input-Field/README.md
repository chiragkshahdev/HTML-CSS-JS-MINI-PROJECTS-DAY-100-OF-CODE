# Day 57 - OTP Input Field

Modern OTP verification UI with auto-focus logic.

## Features
- 6 digit OTP box
- Auto move to next input
- Backspace to go back
- Paste support (full OTP)
- Only numbers allowed
- Verify button

## Tech Stack
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open `index.html`
