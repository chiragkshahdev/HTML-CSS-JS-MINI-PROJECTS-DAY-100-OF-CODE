# Day 59 — Image Editor: Filters

A lightweight, fast, canvas-based image editor built with vanilla HTML, CSS & JS. No libraries.

## ✨ Features

### 1. Preset Filters (One-Click)
- **Grayscale** - Classic black & white
- **Sepia** - Old photo effect
- **Invert** - Negative film look
- **Blur** - 5px blur effect
- **Vintage** - Sepia + High Contrast + Warm
- **B&W Pro** - High contrast grayscale

### 2. Adjustments (Sliders)
- **Brightness** - 0% to 200% (default 100%)
- **Contrast** - 0% to 200% (default 100%)
- **Saturate** - 0% to 200% (default 100%)
- **Hue-Rotate** - 0° to 360° (default 0°)

### 3. Core Actions
- Upload Image (any format)
- Live Preview with `ctx.filter`
- Reset All Filters
- Download as PNG

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Dark UI, Grid Layout
- **JavaScript** - Canvas API
- **API Used:** `CanvasRenderingContext2D.filter`
