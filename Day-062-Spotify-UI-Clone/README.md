# Day 62 - Spotify UI Clone

Responsive Spotify Web Player clone with playlist cards and functional playbar.

## Features
- Left Sidebar: Home, Search, Your Library
- Right Content: Playlists, Trending Now
- Hover Play Button Animation (like original Spotify)
- Fixed Playbar with Play/Pause, Next/Prev, Seekbar
- Dynamic card injection via JS
- Responsive layout

## Tech Stack
- HTML5 + Font Awesome Icons
- CSS3 (Flexbox, sticky header, hover transitions)
- Vanilla JavaScript (DOM + audio logic simulation)

## How it Works
- JS array of songs simulates playlist
- Click any card to play
- Playbar updates song info & time
- Seekbar click to seek (UI only)

## How to Run
Open `index.html` in browser. No dependencies.
