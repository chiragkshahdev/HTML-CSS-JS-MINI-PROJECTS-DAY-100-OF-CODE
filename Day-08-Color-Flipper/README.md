# Day 08 - Random Color Flipper

A beautiful and responsive background color changer built with pure HTML, CSS & JavaScript. Part of my 100 Days of Code Challenge.

### 🚀 Live Demo
> GitHub Pages ON karne ke baad yaha link daal dena
`https://your-username.github.io/100DaysOfCode/Day-08-Color-Flipper/`

### ✨ Features
- 🎨 Generates Random HEX Color on every click
- ⌨️ Press `Spacebar` to change color
- 📱 Fully Responsive Design
- ⚡ Smooth Color Transition Animation
- 💻 Built with Vanilla JS (No Framework)

### 🛠️ Tech Stack
- **HTML5** - Structure
- **CSS3** - Flexbox, Shadows, Transitions
- **JavaScript** - DOM, Random Color Logic, Event Listeners
