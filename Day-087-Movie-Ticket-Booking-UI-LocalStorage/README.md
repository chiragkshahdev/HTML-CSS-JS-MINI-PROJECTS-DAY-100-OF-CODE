# Day 87 - Movie Ticket Booking UI + LocalStorage

100 Days Coding Challenge - Day 87 Project

## Features
- 5 Movies with Different Prices
- 40 Seats Grid (8 x 5)
- Seat Select / Deselect
- Live Price Calculation: Seats x Price
- Booked Seats are Grey (Occupied)
- Booking History with Name, Movie, Seats, Total
- Cancel Booking - Seat wapas free ho jati hai
- LocalStorage - Page refresh karne par bhi booking save rahegi
- Dark Mode 🌙

## Tech Used
- HTML - Structure
- CSS - Grid for Seats + Dark Mode
- JavaScript - Seat Logic + LocalStorage

## How to Run
1. Sabhi 4 files ek hi folder me rakho
2. `index.html` ko browser me kholo
3. Movie select karo, Naam likho, Seat dabao, BOOK NOW dabao
