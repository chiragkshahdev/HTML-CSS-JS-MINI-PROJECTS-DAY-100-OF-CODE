# Day 88 - Full E-commerce Frontend 🛒

A complete frontend e-commerce website built with HTML, CSS & JavaScript.

## Features
- Product Listing with Images, Price & Category
- Search Products (Live Search)
- Filter by Category - Mobile, Laptop, Watch, Shoes
- Sort by Price - Low to High / High to Low
- Add to Cart, Increase / Decrease Quantity, Remove Item
- Cart Sidebar with Total Price Calculation
- Checkout Popup
- Fully Responsive Design

## Tech Used
- HTML
- CSS (Flexbox + Grid)
- JavaScript (Array, Filter, Map, DOM Manipulation)

## How to Run
1. Download all files in same folder
2. Open `index.html` in browser
3. Search, Filter, Add to Cart & Checkout
