# Day 95 - YouTube Clone UI 📺

100 Days Of Code Challenge ka Day 95 project.

## Kya Banaya Hai?
YouTube jaisa Video Feed UI banaya hai.

## Features
- Top Navbar with Search Bar
- Category Chips - All, HTML, CSS, JavaScript
- Left Sidebar - Home, Shorts, Subscriptions
- Video Grid - 6 Video Cards with Thumbnail
- Search karne pe video filter hote hai
- Video pe click karne pe Player khulta hai
- Like + Subscribe button kaam karta hai

## Files
- `index.html` - Structure
- `style.css` - Design / Grid Layout
- `script.js` - Search, Filter, Player Logic
- `README.md` - Project Info

## Kaise Chalaye?
1. Repo download karo
2. `index.html` pe double click karo
3. Browser me khul jayega

## Tech Used
- HTML
- CSS - Grid + Flexbox
- JavaScript - Search & Filter
