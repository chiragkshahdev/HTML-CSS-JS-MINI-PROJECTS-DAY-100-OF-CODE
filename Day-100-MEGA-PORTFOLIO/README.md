## How To Make It Yours?
1. Replace `YOUR NAME` with your real name
2. In `script.js`, in `openProject()` function, replace alert with your real GitHub link:
   `window.open('https://github.com/yourname/day-' + day)`
3. Replace email and social links
4. Add your photo if you want
