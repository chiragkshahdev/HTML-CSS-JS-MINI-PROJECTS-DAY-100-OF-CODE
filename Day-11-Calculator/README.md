### 📸 Features

- ✨ **Glassmorphism UI Design** - Modern and trendy look
- 🌓 Dark / Light Theme Support
- ⌨️ Keyboard Support - Use your keyboard to calculate
- 📱 Fully Responsive - Works on Mobile, Tablet and Desktop
- ⚡ Fast Performance - No lag
- ➕➖✖️➗ All Basic Operations - Add, Subtract, Multiply, Divide
- 🔙 Backspace & Clear Functionality
- 💯 Percentage Calculation

### 🛠️ Tech Stack Used

- **HTML5** - Structure
- **CSS3** - Glassmorphism, Flexbox, Grid, Animations
- **JavaScript (Vanilla)** - Logic, eval handling, keyboard events
