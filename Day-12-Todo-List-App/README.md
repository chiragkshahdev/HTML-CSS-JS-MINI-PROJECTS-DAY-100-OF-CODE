# Day 12 - Todo List App

This is Day 12 of the 100 Days of JavaScript / Web Development challenge.

### Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Data saved in Local Storage - tasks will not disappear after refresh
- Fully responsive design

### Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API

### How to Run
1. Clone the repository
2. Open `Day-12-Todo-List-App/index.html` in your browser

### Concepts Covered
- DOM Manipulation
- Event Delegation
- LocalStorage for data persistence
