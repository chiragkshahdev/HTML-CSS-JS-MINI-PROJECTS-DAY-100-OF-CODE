### Features
- Search weather by city name
- Shows Temperature, Humidity, Wind Speed
- Dynamic weather icons based on weather condition
- Error handling for invalid city
- Fully responsive gradient UI

### API Used
- OpenWeatherMap API - https://openweathermap.org/api

### Tech Stack
- HTML5
- CSS3 (Gradient, Flexbox)
- JavaScript
- Fetch API

### How to Get API Key (Free)
1. Go to openweathermap.org
2. Create free account
3. Go to API Keys section
4. Copy your key and paste in script.js

- Async / Await
- Fetch API
