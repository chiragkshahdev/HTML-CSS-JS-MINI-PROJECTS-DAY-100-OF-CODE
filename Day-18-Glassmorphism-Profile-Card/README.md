### 📚 What I Learned
- `backdrop-filter: blur()` - The core of Glassmorphism
- `background: rgba(255,255,255,0.1)` for translucent glass
- CSS `linear-gradient` with glowing orbs
- Mouse tracking with JavaScript for 3D tilt effect
- Flexbox for perfect centering

### 🛠️ Tech Stack
- HTML5
- CSS3 (Glassmorphism, Animations)
- Vanilla JavaScript
- Boxicons for icons
- Google Fonts - Poppins

### 💡 Features
- [x] True Glassmorphism UI
- [x] Animated floating gradient background
- [x] 3D tilt effect on mouse move
- [x] Follow / Following toggle with JS
- [x] Fully responsive
- [x] Hover animations
