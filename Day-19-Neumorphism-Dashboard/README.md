# Day 19 - Neumorphism Music Player | HTML CSS JS

Soft UI (Neumorphism) is a modern design trend that uses soft shadows to create extruded plastic-like elements.

### Preview
Modern Neumorphic player with real press effect and dark/light mode.

### Features
- [x] True Neumorphism - `box-shadow` light/dark concept
- [x] Dark / Light theme toggle
- [x] Inset shadow on press - Real soft UI feel
- [x] Play/Pause animation with progress bar
- [x] Fully responsive

### What I Learned
- Neumorphism = background color + 2 shadows (dark & light)
- `box-shadow: inset` for pressed state
- CSS variables for theming
- How to create depth without using borders

### Tech Stack
- HTML5, CSS3, Vanilla JS
