# Day 21 - Krrish Mask Loader 🦸‍♂️

> PHASE 2: CSS Mastery & Animation

A custom CSS loader inspired by Krrish's iconic mask. No images, pure CSS with glow and floating animation.

### 🚀 Live Demo
[View Live](https://chiragkshahdev.github.io/HTML-CSS-JS-MINI-PROJECTS-DAY-100-OF-CODE/Day-21-Krrish-Mask-Loader/)

### 🧠 What I Learned
- `border-radius` tricks to make mask shape
- `@keyframes` for float, glow, blink effects
- `box-shadow` for neon glow
- How to make a real-world loader that can be used in any website

### 🛠️ Tech Used
- HTML5
- CSS3 (Animations, Gradients, Shadows)
- 1 line JS for demo hide

### 📂 How to Use
1. Copy `krrish-mask` div to your project
2. Add CSS
3. Show loader while your API/content loads, then hide it.
