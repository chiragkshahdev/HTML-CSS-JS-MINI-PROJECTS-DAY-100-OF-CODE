# Day 23 - Falling Aeroplane Animation ✈️

A realistic falling aeroplane with gravity physics using HTML, CSS & Vanilla JS.

### Features
- Real gravity & velocity physics (no library)
- Rotation increases with speed
- Dynamic shadow scaling
- Cloud parallax animation
- Click plane for lift / Restart button

### Tech Stack
- HTML5
- CSS3 (gradients, animations)
- JavaScript (requestAnimationFrame for physics)

### How to Run
1. Clone repo
2. Open `Day-23-Falling-Aeroplane/index.html`
