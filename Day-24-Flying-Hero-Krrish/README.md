# Day 24 - Flying Hero Krrish 🦸‍♂️

Flying superhero animation inspired by Krrish. Control Krrish in the sky.

### Controls
- W/A/S/D or Arrow Keys - Fly
- Space - Super Speed Boost

### Concepts Used
- Keyboard Events (keydown/keyup)
- CSS Transforms & Hover Animation
- Parallax City Background
- Boundary Collision

### Part of 100 Days Challenge
Day 23 was Falling Aeroplane, Day 24 is the hero who saves it!
