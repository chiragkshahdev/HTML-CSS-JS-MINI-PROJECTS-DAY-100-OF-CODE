# Day 25 - Smoke Effect 💨

Realistic smoke particle effect using HTML5 Canvas and Vanilla JS.

### Features
- Canvas particle system
- Blur + shadow for real smoke look
- Mouse / Touch interactive
- Infinite fading trail
- 60 FPS with requestAnimationFrame

### Tech Stack
- HTML5 Canvas
- CSS3
- JavaScript (OOP - Particle Class)

### Concepts
- Particle physics (velocity, opacity decay)
- Global alpha & shadowBlur for smoke realism

### How to Run
Open `index.html` and move your cursor.
