# Tic Tac Toe Game

Classic 2-player Tic Tac Toe with win detection and scoreboard.

## Features
- 2 Player (X vs O)
- Win highlight animation
- Scoreboard: X wins, O wins, Draws
- Responsive 3x3 grid
- Restart button

## Logic
- 8 winning conditions checked after each move
- Prevents clicking on filled cells
- Draw detection when board full

## How to Play
- Player X starts first
- Click any cell to place your mark
- First to get 3 in a row wins

## Tech
HTML5, CSS3 Grid, Vanilla JS
