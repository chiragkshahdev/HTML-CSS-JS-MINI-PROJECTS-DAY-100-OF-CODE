# Day 34 - Scroll Progress Bar

A simple and smooth scroll progress indicator that shows how much you have scrolled on a page. Built with HTML, CSS & JS.

### ✨ Features
- Fixed top progress bar
- Smooth width animation on scroll
- Gradient color effect
- Works on all screen sizes
- Pure JS - no library

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

### 📂 Files
- `index.html` - Structure
- `style.css` - Styling
- `script.js` - Scroll logic

### 🚀 How It Works
```js
scrolled % = (window.scrollY / (documentHeight - windowHeight)) * 100
