# Day 37 - Notes App with localStorage

A complete notes app with title, content, search and persistent storage.

### ✨ Features
- Add notes with Title + Content
- Auto-save in localStorage
- Search notes
- Delete notes
- Date & time stamp
- Responsive grid layout

### 🛠️ Tech Stack
HTML5, CSS3, JavaScript + localStorage

### 💾 Data
All notes saved in browser, no backend needed.
