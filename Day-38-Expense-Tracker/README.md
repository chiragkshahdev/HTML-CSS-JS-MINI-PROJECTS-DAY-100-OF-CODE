# Day 38 - Expense Tracker

Track your income and expenses with live balance calculation.

### ✨ Features
- Add Income / Expense
- Live Balance, Income, Expense calculation
- Transaction History
- Delete transactions
- Saved in localStorage
- Hover to delete effect

### 🛠️ Tech Stack
HTML5, CSS3, JavaScript

### 💡 Logic
- Positive amount = Income
- Negative amount = Expense (-100 for food)
