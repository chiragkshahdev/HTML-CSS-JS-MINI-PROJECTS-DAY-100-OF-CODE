# Day 42 - Movie Search App

Search any movie and get poster, title, year using OMDB API.

### ✨ Features
- Live search
- Grid layout
- Hover effect
- Poster + Title + Year
- Default Avengers load

### 🛠️ Tech Stack
HTML, CSS, JS + OMDB API

### 🔑 API
1. Free key from https://www.omdbapi.com/apikey.aspx
2. Replace `thewdb` with your key (demo key has limit)

### ▶️ Endpoint
`https://www.omdbapi.com/?apikey=YOURKEY&s={movieName}`
