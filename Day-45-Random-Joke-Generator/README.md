# Day 45 - Random Joke Generator 😂

A fun and responsive Random Joke Generator built with HTML, CSS & JS.

## Features
- Fetch jokes from JokeAPI v2
- Category filter: Any, Programming, Pun, Dark
- Two-part jokes (Setup + Delivery)
- Copy to clipboard
- Text-to-Speech
- Fallback jokes if API fails
- Mobile responsive + Animated UI

## Tech Stack
- HTML5
- CSS3 (Flex, Gradient, Animations)
- Vanilla JavaScript (Fetch API, Web Speech API)

## API Used
https://v2.jokeapi.dev/

## How to Run
1. Clone/download
2. Open `index.html` in browser
3. Click Generate Joke
