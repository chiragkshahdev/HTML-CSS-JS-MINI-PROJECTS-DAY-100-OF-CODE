### 🎯 Features
- Drag & Drop file upload
- Click to Browse support
- Multiple file support
- File name & size preview
- Dragover animation & hover effects
- Fully responsive
- No external libraries

### 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Transitions)
- Vanilla JavaScript (Drag & Drop API)
