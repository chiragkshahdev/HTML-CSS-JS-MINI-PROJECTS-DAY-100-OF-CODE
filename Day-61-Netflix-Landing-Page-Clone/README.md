# Day 61 - Netflix Landing Page Clone

A responsive Netflix India landing page clone built with HTML, CSS, and JavaScript.

## Features
- Hero section with email signup
- Background overlay effect like original Netflix
- TV section with video inside image
- FAQ accordion hover effect
- Fully responsive (mobile + desktop)
- Language toggle (English / Hindi)

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Vanilla JavaScript

## Preview
Sections included:
1. Navbar with logo & Sign In
2. Hero - Unlimited movies...
3. Enjoy on your TV
4. Download offline
5. FAQ
6. Footer

## How to Run
1. Clone repo
2. Open `index.html` in browser
3. No build step needed

## Learning Outcome
Practiced positioning, z-index, background overlay, responsive design and DOM events.
