# Day 63 - Zomato / Swiggy Hero Section

Clone of Zomato's hero landing with Swiggy's quick delivery banner twist.

## Features
- Full-screen hero with dark overlay (like Zomato)
- Navbar: Get the App, Login, Signup
- Location dropdown + Search bar
- Trending pills (Biryani, Pizza etc.)
- 3 Feature Cards: Order Online, Dining, Nightlife (hover scale effect)
- Swiggy-style orange gradient banner

## Tech Stack
- HTML5
- CSS3 (Flexbox, backdrop-filter, responsive)
- Vanilla JS

## Interactions
- Search button validates input
- Enter key triggers search
- Click trending pill auto-fills search
- Card click alerts section

## Responsive
Mobile: Search box stacks vertical, navbar hides extra links.

## How to Run
Open index.html
