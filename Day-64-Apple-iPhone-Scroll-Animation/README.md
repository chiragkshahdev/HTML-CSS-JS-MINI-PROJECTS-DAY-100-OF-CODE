# Day 64 - Apple iPhone Scroll Animation

Apple.com inspired sticky scroll effect.

Features:
- 3D iPhone rotates on scroll
- 400vh sticky container
- Screen content sync with scroll
- Right features highlight
- Pure HTML/CSS/JS - no library
- Responsive

How to Run:
Just open index.html

How it Works:
progress = -top / (height - vh) drives rotateY, rotateX, scale
