# Day-66 - E-commerce Product Page

A modern, responsive single product page for an online store.

## Features
- Product image gallery with thumbnail switching
- Color variant selector
- Quantity selector with live price update
- Add to Cart with slide-in cart drawer
- Buy Now flow
- Wishlist toggle
- Toast notifications
- Fully responsive (Mobile + Desktop)

## Tech Stack
- HTML5 - Structure
- CSS3 - Styling, Grid, Flexbox
- Vanilla JavaScript - Interactivity (No framework)

## File Structure
Day-66-E-commerce-Product-Page/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Download all 4 files in same folder
2. Open `index.html` in browser
3. No server / build needed
