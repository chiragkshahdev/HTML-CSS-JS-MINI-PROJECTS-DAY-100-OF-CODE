# Day-72 - Portfolio Website V1

A modern, responsive personal portfolio website.

## Features
- 🏠 Hero with Typing Animation (Frontend Developer / 100 Days of Code...)
- 🌙 Dark Mode Toggle (saved in localStorage)
- 📱 Mobile Menu - Hamburger for small screens
- 👤 About Section - Who am I, Services, Details
- 📊 Skills with Animated Progress Bars (HTML 95%, JS 88%...)
- 💼 Projects Grid with Filter - All / Web App / Clone / E-commerce
- 📄 Download CV Button (Demo)
- 📬 Contact Form with Validation + Success Message
- 🔝 Back to Top Button
- ✨ Scroll Active Nav Highlight
- 💾 Dark Mode Persistence

## Tech Stack
- HTML5 - Structure
- CSS3 - Grid, Flexbox, Gradients, Animations
- Vanilla JavaScript - Typing Effect, Filters, Dark Mode, Form

## File Structure
Day-72-Portfolio-Website-V1/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run
1. Keep all 4 files in same folder
2. Open `index.html` in browser
3. Try: Dark Mode, Project Filters, Contact Form, Mobile Menu
4. Edit your name, email, projects in `index.html` / `script.js`

## How to Customize (Important!)
In `index.html`:
- Change Name: `You Dev` -> Your Name
- Change Email / Phone in Contact section
- Change Location: Virar -> Your City

In `script.js`:
- Change `PROJECTS` array - Add your real projects
- Change `SKILLS` array - Your skills + %
- Change `ROLES` - Your titles
