# Day 86 - Full Todo App with Dark Mode + Categories

100 Days Coding Challenge - Day 86 Project

## Features
- Add / Delete / Complete Todo
- Categories: College, Personal, Work, Meme
- Filter by Category
- Search Todos
- Priority: Normal 🟢 / Important 🔴
- Dark Mode Toggle 🌙
- Data Saved in LocalStorage (Browser band karne par bhi save rahega)

## Tech Used
- HTML - Structure
- CSS - Styling + Dark Mode
- JavaScript - Logic + LocalStorage

## How to Run
1. Sabhi 4 files ek hi folder me rakho
2. `index.html` ko double-click karke browser me kholo
3. Kaam likho, Category select karo, ADD TODO dabao

## Team Division (5 Members)
- Member 1: HTML Structure + README
- Member 2: CSS + Dark Mode
- Member 3: JS - Add / Delete Logic
- Member 4: JS - Filter + Search + LocalStorage
- Member 5: Testing + Final Presentation
