# Day 93 - ChatGPT Clone UI 🤖

100 Days Of Code Challenge ka Day 93 project.

## Kya Banaya Hai?
ChatGPT jaisa dikhne wala Chat UI banaya hai.
Asli AI nahi hai, sirf UI + Fake Reply logic hai.

## Features
- Left Sidebar with Chat History
- Chat Area with User / AI Avatar
- Input Box with Send Button
- Enter dabane pe message jata hai
- AI 1 sec baad auto reply karta hai
- New Chat button se chat clear ho jati hai

## Files
- `index.html` - Structure
- `style.css` - Design / Styling
- `script.js` - Logic

## Kaise Chalaye?
1. Repo download karo
2. `index.html` pe double click karo
3. Browser me khul jayega

## Tech Used
- HTML
- CSS
- JavaScript
