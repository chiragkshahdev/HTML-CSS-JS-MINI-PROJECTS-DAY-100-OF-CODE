# Day 94 - LinkedIn Clone Feed UI 💼

100 Days Of Code Challenge ka Day 94 project.

## Kya Banaya Hai?
LinkedIn jaisa Feed UI banaya hai. Sirf dikhne me nahi, kaam bhi karta hai.

## Features
- Top Navbar with Search
- Left Profile Card with Views / Connections
- Center Feed with Post Box
- Naya Post add kar sakte ho
- Like button - click karne pe count badhta hai
- Comment likh sakte ho
- Right side Follow / Following button kaam karta hai

## Files
- `index.html` - Structure
- `style.css` - Design / Styling
- `script.js` - Like, Comment, Post, Follow Logic
- `README.md` - Project Info

## Kaise Chalaye?
1. Repo download karo
2. `index.html` pe double click karo
3. Browser me khul jayega

## Tech Used
- HTML
- CSS - Flexbox Layout
- JavaScript - DOM Manipulation
