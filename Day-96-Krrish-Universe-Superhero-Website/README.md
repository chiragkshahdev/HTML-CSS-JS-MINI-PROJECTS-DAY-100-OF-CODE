# Day 96 - Krrish Universe - Superhero Website 🦸

100 Days Of Code Challenge ka Day 96 project.

## Kya Banaya Hai?
Bollywood ke Superhero Krrish pe based ek Fan Website banayi hai.
Sirf design nahi, poora interactive hai.

## Features
- Hero Section with Krrish Card + Power Bar
- Become Krrish Button - Click karne pe Krrish ban jate ho
- 4 Powers - Super Speed, Strength, Flying, Mind Reading
- Click karne pe Power Bar change hota hai
- Villains Section - Kaal, Dr. Arya se Fight kar sakte ho
- Random Fight Result - Har baar alag dialogue
- Jadoo Section - Jadoo ko uthao, Jadoo Dance karwao
- Join Universe - Apna Superhero naam likh sakte ho

## Files
- `index.html` - Structure
- `style.css` - Dark Theme + Gold Theme
- `script.js` - Powers, Fight, Jadoo Logic
- `README.md` - Project Info

## Kaise Chalaye?
1. Repo download karo
2. `index.html` pe double click karo
3. Browser me khul jayega

## Tech Used
- HTML
- CSS - Flexbox + Grid
- JavaScript - DOM, Random, Prompt

## Disclaimer
Krrish is a Bollywood character. This is a fan-made learning project.
