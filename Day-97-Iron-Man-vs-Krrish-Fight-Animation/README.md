# Day 97 - Iron Man vs Krrish - Fight Animation PRO Version ⚔️

100 Days Of Code Challenge ka Day 97 project.

## Kya Banaya Hai?
Ek poora Fighting Game banaya hai. Bollywood vs Hollywood!
Krrish vs Iron Man - Kaun jeetega? Tum decide karo!

## Features - PRO Version
- Live Health Bar - Dono ki HP ghatti hai
- Energy System - Special attack ke liye energy chahiye
- Fight Animation - Punch marne pe character hilta hai
- Screen Shake - Heavy attack pe poora arena hilta hai
- Damage Text - Kitna damage hua, dikhta hai
- Jadoo Heal - Krrish ko Jadoo heal karta hai
- Jarvis Auto Attack - Iron Man computer se khud ladta hai
- Random Attack - Iron Man har baar alag attack karta hai
- Round System - 3 Round ka Match
- Scoreboard - Kitni baar kaun jeeta
- Winner Popup - Jeetne pe trophy + dance animation
- Dead Animation - Haarne wala ulta gir jata hai

## Controls
- Krrish: Punch (10 dmg), Flying Kick (15 dmg), Special (25 dmg), Heal (+20 HP)
- Iron Man: Jarvis Auto Attack - Repulsor, Missile, Unibeam

## Files
- `index.html` - Structure
- `style.css` - Arena, Animation, Health Bar
- `script.js` - Fight Logic, Random, Score
- `README.md` - Project Info

## Kaise Khelo?
1. Repo download karo
2. `index.html` pe double click karo
3. Krrish ke attack dabao
4. Iron Man jawab dega
5. Jiski HP pehle 0 hogi, wo harega

## Tech Used
- HTML
- CSS - Keyframes Animation, Flexbox
- JavaScript - Game Logic, Random, DOM
