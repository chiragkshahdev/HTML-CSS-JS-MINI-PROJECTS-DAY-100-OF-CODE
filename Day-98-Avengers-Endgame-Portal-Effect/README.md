# Day 98 - Avengers Endgame Portal Effect 🌀

100 Days Of Code Challenge ka Day 98 project.

## Kya Banaya Hai?
Endgame ka sabse famous scene browser me banaya hai.
Doctor Strange portals kholta hai, saare heroes bahar aate hai, aur Thanos snap ho jata hai.

## Kaise Khelo? - 3 Steps
1. **Open Portals** dabao - 6 ghoomte hue orange portals khulenge
2. **Avengers Assemble** dabao - 9 heroes portal se bahar aayenge - Krrish, Iron Man, Thor, Spider Man, Doctor Strange, Hulk, Hawkeye, Captain America, Jadoo
3. **Iron Man Snap** dabao - Saare heroes attack karenge, Thanos ki HP 0 hogi, aur wo dust ban ke ud jayega

## Features - PRO Version
- Portal Spin Animation - CSS Keyframes se ghoomta portal
- Hero Entry Animation - Portal se hero bahar aane wala effect
- Thanos Health Bar - Snap pe HP ghatti hai
- Snap Dust Effect - Thanos blur hoke gayab hota hai
- Step by Step Buttons - Pehle portal, phir assemble, phir snap
- Battle Log - Har step pe story dikhti hai
- Winner Popup - I Love You 3000 wala message

## Files
- `index.html` - Structure
- `style.css` - Portal Animation, Hero Entry, Snap Effect
- `script.js` - Portal Logic, Assemble, Snap Logic
- `README.md` - Project Info

## Kaise Chalaye?
1. Repo download karo
2. `index.html` pe double click karo
3. Browser me khul jayega

## Tech Used
- HTML
- CSS - Keyframes, Animation, Gradient
- JavaScript - setTimeout, DOM, Array Loop
